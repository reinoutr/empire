### 4 sept - [Typografie deep dive, gegeven door Diederik & Schetsen deep dive, gegeven door Charley]

Op deze dag kreeg ik deep dives over typografie en over schetsen. Ik had deze deep dives gekozen, omdat ik vormgeving en het visuele aspect van het proces zelf heel leuk vind om te doen. In de deep dive van Diederik kregen we de geschiedenis van bepaalde lettertypes uitgelegd en hoe ze tot stand zijn gekomen. We kregen de opdracht om woorden te bedenken die bij ons opkwamen bij 2 foto's van Dolly Parton. Daaruit gingen we verder woorden uitkiezen en meer woorden verzinnen, waaruit we een lettertype gingen zoeken die het beste bij de gekozen woorden past.

### 2 sept - [Deep dive HTML & CSS basics, gegeven door Justus + Deep dive over CSS fonts met kleur en effecten, gegeven door Sanne]

We kregen een les over de basics van HTML & CSS van Justus. Hij legde ons uit over de geschiedenis van HTML en CSS en over de functie van de verschillende codetalen. Na de deep dive van Justus heb ik ook de deep dive van Sanne bijgewoont. In deze deep dive hadden we geleerd hoe we fonts kunnen importeren en in met code in CSS kunnen zetten. Verder hadden we ook oefeningen hiermee gedaan. Deze deep dives had ik o.a. gekozen, omdat ik coderen nog heel lastig vind en het is het begin van het schooljaar, dus ik moet er nog even inkomen.
